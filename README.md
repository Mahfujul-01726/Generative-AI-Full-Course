# 🚀 Generative AI Full Course: From Zero to Hero

![Generative AI Course Banner](assets/banner.png)

Welcome to the **Generative AI Full Course**! This repository is a comprehensive guide designed to take you from the fundamental concepts of AI to building and deploying advanced multi-agent systems and custom LLM applications.

---

## 📊 Course Overview
This bootcamp is structured into **7 Intensive Modules**, covering everything from Transformers and LangChain to Open Source LLMs and AI Agents.

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Mahfujul-01726/Generative-AI-Full-Course.git
cd Generative-AI-Full-Course
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install dependencies
*Each day might have its own `requirements.txt`. Please check individual folders.*
